# Haru Bake 评论自动回复 · 하루베이크 댓글 자동응대

SNS 平台自动化实习作业：Instagram 评论「收集 → 意图分类 → 策略检查 → 生成回复 → 执行」的自动回复演示，附自动化结构与政策·伦理审查。界面支持中文 / 韩文切换。

- 在线访问：https://garyklay28.github.io/haru-reply-lab/
- 单文件静态页面（`index.html`），不会向真实的 Instagram 发送任何内容，API 调用只在页面日志里模拟。
- 独立网址只提供规则引擎；Claude 引擎和新评论的自动翻译只在 Claude 应用里打开时可用。
